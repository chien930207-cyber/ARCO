# ARCO｜樂理練習室

把樂理，帶進演奏。

ARCO 是以繁體中文設計的樂理學習網站。從識譜、節奏、音程與和弦，逐步練到調式、編曲與進階和聲。每課先理解觀念，再透過試聽、互動實作與演奏任務，把知識用出來。

**目前版本：2.1.0**　｜　100 級課程　｜　1,000 題練習　｜　100 個互動實作

## 如何開始

單人學習、合成試聽、程度測驗與 AI 對戰不需要 API 金鑰，也不依賴網路。

第一次進入可選擇完成 15 題程度測驗、從第 1 級開始，或先瀏覽課程。正式版預設為正常闖關模式。

## 學習方式

| 功能 | 使用方式 |
| --- | --- |
| 100 級課程 | 每級一個主題，包含深入講解、推導示例、容易混淆的觀念與冷知識。 |
| 動手做一次 | 音高／和弦按鍵、節奏格與編配選擇任務；可以試聽、核對與重做。 |
| 帶進演奏 | 每課有具體情境、三步練習與自我檢查標準，可用樂器、拍手或哼唱實踐。 |
| 課程挑戰 | 每級 10 題，不限時；答對至少 8 題才記為實際通過。 |
| 錯題本 | 課程答錯的題目自動收錄，複習答對後移出。 |
| 附加對戰 | 真人雙人對戰在上方；三種難度的 AI 陪練在下方。對戰不影響課程晉級。 |

互動實作核對的是輸入的音符、節奏或選項。演奏任務的勾選是自我練習紀錄，網站不會錄音，也不會自動評分真人的音準、節奏或指法。

## 15 題程度測驗

完整測驗固定 **15 題**，依五個難度範圍各抽 3 題。每個範圍都涵蓋觀念、推算／辨讀與情境／分析題，並盡量分散到不同課程。

| 抽樣範圍 | 主要主題 | 題數 |
| --- | --- | --- |
| 第 1–20 級 | 識譜與節奏 | 3 |
| 第 21–40 級 | 音程與調性 | 3 |
| 第 41–60 級 | 和弦與進行 | 3 |
| 第 61–80 級 | 延伸與調式 | 3 |
| 第 81–100 級 | 樂句與進階和聲 | 3 |

同次測驗不重複題目，選項順序也會打散。重測優先抽取這個瀏覽器尚未看過的題目；當對應難度與題型的題池用盡，才重用最久未見的題目。離開未完成測驗不會改變起點，但已出現的題目仍列入避重紀錄。清除瀏覽資料或換裝置後，避重紀錄不會自動跟著轉移。

每個範圍至少答對 2 / 3 題，才作為繼續往後建議的依據。前段有缺口時，不會單憑後段答對就跳過。這是短版學習分流，建議起點為第 1、20、40、60、80 或 100 級；不是經過統計校準的能力分數，也不對應官方檢定。

確認前可以更改選擇；送出後同一題只記錄一次。程度測驗不計入課程成績或錯題本。

### 建議第 40 級，代表什麼？

按下「採用建議」後，**第 1–40 級都可以直接進入，包括第 40 級**。可以回看教材、做實作，也可以自行挑戰，不必先闖完第 1–39 級。

這些課程標示為「測驗開放」，不會偽造滿分或已通過紀錄。即使回頭挑戰沒有及格，開放範圍也不會被收回。第 40 級挑戰達到 8 / 10 後，再解鎖第 41 級，以此類推。

重新測驗的建議較低時，先前已採用的開放範圍仍保留。只有在設定中主動取消測驗開放，才會重新依正式成績判定可進入的課程。

## 雙人與 AI 對戰

真人對戰由一人建立四位數房號，另一人加入。兩人收到相同題目與選項，每題限時 20 秒；雙方都準備好，才會進入下一題。連線中斷會停止本局，不會偷偷切換成電腦對手。

AI 陪練有入門、標準與進階三種反應速度及答對傾向。這是本機規則式電腦對手，不使用生成式模型，也不根據你的當題答案改答案。題目難度由所選課程決定。

真人網路對戰採 PeerJS / WebRTC，需連網；首次開房或加入時才載入 PeerJS。公司防火牆、行動網路或 NAT 可能阻止連線，本專案未提供私人 TURN 中繼。四位數代碼只方便邀請，不是密碼；對戰沒有帳號、排名或防作弊後端。

## 進度與隱私

進度保存在目前瀏覽器的 `localStorage`，沒有雲端帳號或分析追蹤。保存內容包括課程成績、錯題、實作紀錄、偏好、測驗開放範圍與已見題目編號。不同瀏覽器、裝置、網站來源與本機檔案位置，可能無法共用這些資料。

在右上角設定使用「匯出進度」備份 JSON，再於另一個環境「匯入進度」。2.1.0 可讀取 v1、v2 與 v3 進度格式；匯入會取代目前資料，操作前會要求確認。本機檔案要改放到 GitHub Pages 時，請先匯出再匯入。

設定裡保留「自由選關測試」，可暫時開放 100 級；測試成績與正式成績分開。這不是管理員登入或存取權限，也不會把測試成績轉成正式通過。

網路對戰會讓第三方訊號服務參與連線建立，對手也會收到暱稱與答題資料；WebRTC 連線可能揭露網路位址。請勿使用敏感暱稱。教材與影片連結會開啟外部網站，適用各站的隱私政策。
