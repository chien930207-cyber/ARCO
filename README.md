# ARCO｜樂理練習室

**讓觀念，成為聽得懂的音樂。**

ARCO 是一個樂理學習網站。從識譜、節奏、音程與和弦，逐步練到調式、編曲與進階和聲。每課先理解觀念，再透過試聽、互動實作與演奏任務，把知識用出來。

無論是剛開始認識樂譜，或已經會演奏、想補強樂理，都可以從適合自己的起點開始。

**100 級課程 | 1,000 題課程挑戰 | 3,000 題對戰題庫**

## 從哪裡開始？

**開始 15 題程度測驗**：完成並採用結果後，從測驗起點逐關學習。

**不測驗，從第 1 級開始**：直接學基礎，只開放第 1 級。

程度測驗依難度分層隨機抽題，不限時。完成後可查看建議起點，並對照自己的答案、正確答案與解析。

兩條路線都採逐關學習：每關 10 題，**答對至少 8 題，解鎖下一關。**已開放的課程可隨時回去複習。

例如測驗建議第 40 級：從第 40 級接著練，第 1–39 級可複習，不用重新闖關。第 40 級達 8 / 10 後開放 41 級。測驗開放與實際通過分開記錄。

## 每一課，把觀念用出來

**理解觀念 → 動手練習 → 帶進演奏 → 開始挑戰**

包含觀念說明、例題、常見誤區、合成試聽、互動實作、演奏任務與延伸教材。

| 學習方式 | 可以做什麼 |
| --- | --- |
| 互動琴鍵與試聽 | 點選琴鍵、播放示範，聽見音高與和聲的差異。 |
| 音符與節奏練習 | 輸入音符、編排節奏或選擇編配，再核對結果。 |
| 演奏任務 | 依步驟實際練習，把所學帶進伴奏、編曲或合奏。 |
| 錯題複習 | 課程錯題自動收錄，方便回頭補強容易混淆的觀念。 |

互動實作核對的是你輸入的答案；實際演奏則依課程提供的標準自我檢查。網站不會錄音或自動評分真人演奏。

## 換個節奏，來場對戰

**雙人連線對戰**：一人建立房間，另一人輸入四位數房號加入。雙方使用相同題目與選項順序，從第 1–100 級全範圍出題。

**AI 陪練**：選擇入門、標準或進階對手，並自行勾選章節、個別課程或級數範圍。可快速選取目前課程，也能挑戰還沒上過的內容。

真人與 AI 對戰都是每局 10 題：**先看題目 5 秒 → 選項出現後 30 秒作答 → 顯示正確答案 3 秒 → 自動開始下一題**。第 10 題是三倍分數的魔王題。

積分依題目難度、答題速度與連對次數計算。對戰是額外練習，不會改變課程成績或解鎖進度。

第 10 題顯示答案後自動進入結算，才顯示錯題、你的答案、正確解答與觀念解析。可在「錯題」與「全部 10 題」切換。這份對戰回顧僅留在本局，不自動寫入課程錯題本。

AI 為本機規則式電腦對手，不使用生成式模型，也不會根據你當題的選擇更改答案。

## 語言

右上角點開語言選單，即可切換 **繁體中文 / English / Deutsch**。預設為繁體中文。

三種語言都包含介面、100 課教材、題目與選項、解析、實作任務與操作提示。譯文隨網站內建，不需即時翻譯服務或 API 金鑰。切換語言不會重設進度、重新抽題或改變已選答案。

音名統一使用 C D E F G A B。在德文命名中，本站的 B 對應 H，B♭ 對應德文 B；所有語言的發聲與答案依據相同。外部教材與影片連結維持原來的語言。

## 開始使用

開啟網站，或下載本專案後用瀏覽器開啟 `index.html`。不需註冊帳號、安裝應用程式或設定 API 金鑰。

課程、程度測驗、內建試聽與 AI 陪練可在本機離線使用；真人網路對戰與外部教材連結需要連網。音量與動態效果可在設定中調整。

雙人對戰請使用相容版本。公司或校園網路、防火牆等環境可能影響連線；「同瀏覽器雙分頁測試」僅供本機測試，不是跨裝置連線模式。

## 進度保存與備份

測驗起點、課程成績、錯題與練習紀錄保存在目前瀏覽器，**沒有雲端帳號或跨裝置自動同步**。換瀏覽器、裝置或網址，以及清除網站資料前，請先備份。

在 **設定 → 匯出進度** 下載 JSON 備份，需要還原時再選擇「匯入進度」。匯入會取代目前進度，請先備份。語言與對戰偏好不包含在這份課程進度備份中。

已完成的程度測驗不提供直接重測。需要從頭開始時，可在設定最下方選擇 **恢復原廠設定 → 初始化**。確認後會清除本機 ARCO 進度、錯題、偏好與自動備份，不只是重做測驗。已匯出的 JSON 檔案不受影響。

## 關於課程與回饋

100 級是 ARCO 的自編學習路線，不對應官方檢定。程度測驗用來建議起點，不是正式能力評量。題庫尚未完成音樂教師逐題審核與難度統計校準。

參考教材包括 [musictheory.net](https://www.musictheory.net/lessons)、[Open Music Theory](https://viva.pressbooks.pub/openmusictheory/) 與 [Ableton Learning Music](https://learningmusic.ableton.com/)。

發現題目有誤或操作異常時，請附上課程級數、題目內容、使用語言與操作步驟；截圖也能幫助釐清問題。

網站場景為 AI 生成圖像，不代表實際場地。本專案尚未指定開源授權；第三方教材與元件維持各自的授權條款。
